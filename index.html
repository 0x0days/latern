How it works

One JSON file is the whole database

Transcripts are split into short overlapping blocks, each stamped with the second it starts at, and saved as transcripts.json. Replacing that single file updates the entire site.

Search happens on your device

On first visit the file is downloaded once and indexed in memory by Orama, with the English stemmer enabled and stop-word removal disabled so specialised terms are matched exactly as people type them.

Results open at the exact second

Every matching block links to youtube.com/watch?v=…&t=…s, so a click lands you right where the topic is discussed.

Frequently asked questions

Is this the official website of TheMuslimLantern?

No — this is an unofficial fan-made tool. The official channel is youtube.com/@TheMuslimLantern.

Are my searches stored or tracked?

No. Search runs fully in your browser with no analytics and no cookies. Nothing you type is ever uploaded.

How can new videos be added?

Use the free Google Colab script on the Data Pipeline page. It fetches the channel's videos and captions, chunks them with timestamps, and exports a new transcripts.json.
